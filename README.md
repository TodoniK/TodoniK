## About

I design cloud platforms and the pipelines that ship to them. At **Orange** I guide application migrations to Azure and Orange's private cloud: target architectures on Azure Container Apps, AKS and WAF v2, architecture dossiers, FinOps. Before that I spent three years as a full stack engineer on the Orange online store, where an LLM pipeline I built cut product publishing time by 75%.

Off the clock, I run my own cloud on Oracle with Dokploy and Traefik, self-host autonomous agents, and write Rust when token budgets get tight. I also run [Casa Mocha](https://www.casa-mocha.fr), a small studio building custom websites for artisans.
